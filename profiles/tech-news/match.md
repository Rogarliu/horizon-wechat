# 科技资讯 profile

这个 profile 收「科技资讯」，不收「技术文章」。

## 收什么

- 公司发布、产品更新、融资并购、人事变动、行业格局变化
- 有话题性的 AI 进展、有趣的实验和发现、意外的结果
- 影响普通用户的政策、隐私、安全事件、价格变动
- 被广泛讨论的行业观点和争议
- 消费电子、软硬件新品、日常能用上的工具

## 不收什么

- 学术论文、技术原理讲解、源码分析、性能调优、benchmark 刷榜
- 教程、踩坑记录、工程实践复盘、架构设计取舍
- 需要专业背景才能读懂的深度长文
- 招聘、纯推广、例行版本更新、无信息量的转载
- 纯财务/股价视角的市场分析

判断标准很简单：**一个对科技感兴趣但不在这个行业工作的人，会不会想点开看？**
